# Реализация стандартных контейнеров STL (C++)

Учебный проект: собственные реализации контейнеров, адаптеров и вспомогательных типов из стандартной библиотеки C++ с демонстрацией работы (консольные примеры и интерфейс на Qt Widgets).

## Структура репозитория

| Папка | Контейнер / Структура данных | Содержимое |
|-------|------------------------------|------------|
| [`vector/`](vector/) | `vector` | Шаблонный динамический массив с аллокатором, итераторами, `emplace`, перемещением; консольный пример [`vactor.cpp`](vector/vactor.cpp) |
| [`deque/`](deque/) | `deque` | Шаблонный двусвязный блочный буфер (двусторонняя очередь) с собственным итератором, поддержкой аллокаторов и методами `push`/`pop` с обоих концов |
| [`heap/`](heap/) | `priority_queue` (Heap) | Реализации двоичной кучи (Max-Heap): на базе вектора (`ArrayHeap`) и на базе указателей (`ListHeap` с использованием `std::shared_ptr`/`weak_ptr`) |
| [`string/`](string/) | `string` | Класс строки с SSO (small string optimization), итератор, сборка как shared-библиотека (`StringLib.pro`) |
| [`pair/`](pair/) | `pair` | Шаблон `pair<T1, T2>` с конструкторами копирования и перемещения |
| [`map/`](map/) | `map` | Ассоциативный контейнер на красно-чёрном дереве (`RBTree`) |
| [`set/`](set/) | `set` | Упорядоченное множество на том же `RBTree` |
| [`unordered_map/`](unordered_map/) | `unordered_map` | Хеш-таблица с цепочками (bucket + list), собственный итератор |
| [`demos/qt-pair-vector/`](demos/qt-pair-vector/) | — | Qt-приложение: `Vector` + `pair`, операции push/pop/clear и вложенные контейнеры |
| [`demos/qt-associative-containers/`](demos/qt-associative-containers/) | — | Qt-приложение: `Map`, `Set`, `unordered_map` с UI для insert/erase/find/clear |

## Что реализовано (кратко)

*   **Vector** — управление памятью через `std::allocator`, реаллокация, `PushBack` / `PopBack`, вставка и удаление, прямые и обратные итераторы, `Emplace` / `EmplaceBack`.
*   **Deque** — многоблочная организация памяти для исключения полного копирования при расширении в обе стороны, реализация произвольного доступа (`operator[]`), методы `push_front`/`pop_front` и `push_back`/`pop_back`.
*   **Priority Queue / Heap** — две вариации структуры данных Max-Heap:
    *   *ArrayHeap*: компактное представление дерева на основе динамического массива с базовой арифметикой индексов для переходов к потомкам/родителям.
    *   *ListHeap*: представление в виде связанного бинарного дерева на узлах с управлением жизненным циклом через умные указатели `std::shared_ptr` и `std::weak_ptr` для предотвращения утечек памяти и циклических зависимостей.
*   **String** — короткие строки хранятся внутри самого объекта (SSO до 15 символов), длинные — выделяются в куче; реализованы базовые операции и итератор по символам.
*   **Pair** — аналог `std::pair` для использования в собственном `Vector` и в демонстрационных макетах.
*   **Map / Set** — общая база на основе сбалансированного красно-чёрного дерева (`RBTree`), поддерживающего операции обхода, вставки, удаления и поиска. Для `Set` добавлена обёртка итератора с const-семантикой.
*   **Unordered\_map** — базовая хеш-таблица с методом цепочек для разрешения коллизий, автоматическим перехешированием при превышении коэффициента заполнения (load factor) и итератором по корзинам.

## Сборка

Требования: **C++17**, **Qt 5/6** (только для демонстрационных проектов в `demos/`), инструментарий **qmake** (или среда Qt Creator).

```bash
# String 
cd string && qmake StringLib.pro && make

# Vector 
cd vector && c++ -std=c++17 vactor.cpp -o vector_demo && ./vector_demo
